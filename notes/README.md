# Notes

A learning journal. One small file per thing learned.

Create a new one:

```sh
npm run note -- "how npm scripts work"
```

That creates `notes/YYYY-MM-DD-how-npm-scripts-work.md` from a template.
Short and messy is fine; the habit matters more than polish.
